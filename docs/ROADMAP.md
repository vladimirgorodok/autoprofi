# Дорожная карта

Клон повторяет рабочий сценарий оригинала. Дальше — то, что сделает его
удобнее в реальной работе.

## Что уже сделано в 1.2.0

- Архив данных: ZIP с `01-vehicles.csv` … `11-finances.csv`, `manifest.json`,
  `README.txt` и полной JSON-копией.
- Импорт ZIP/JSON и CSV-архивов оригинала; CSV важнее JSON для таблиц,
  JSON — для настроек и чата.
- Поля из оригинальных данных: VIN и тип ТС, примечание автомобиля, вес
  груза и тип загрузки рейса, топливо на выезде/возврате, остановки.
- На Android экспорт сохраняется через системный диалог «Создать документ».

## Что уже сделано в 1.1.0

- Редактируемые справочники: фирмы, места, грузы, АЗС, статьи расходов.
- Подсказки из справочников в рейсах, путевых листах, заправках и финансах.
- Убраны цена топлива, денежный учёт заправок и профиль водителя.
- Миграция данных версии 1 → 2 без потери рейсов, листов и финансов.

## Ближайшие улучшения

1. **Смена и геометка.** Автоматически фиксировать начало/конец смены,
   подставлять адрес и пробег, напоминать закрыть лист вечером.
2. **Фото документов.** Чеки АЗС, ТТН и фото одометра прямо в карточке
   заправки/рейса (IndexedDB, без облака).
3. **Сканер чеков.** Распознавание литров и даты с фото чека на
   устройстве (ML Kit / Tesseract), ручное подтверждение.
4. **Маршрут и пробки.** Кнопка «Открыть в навигаторе», расчёт километража
   по точкам, подсказка платных участков.
5. **Долги и выплаты.** Кто и сколько должен за рейс, частичные оплаты,
   напоминания контрагентам.
6. **Печать и PDF.** Полноценный PDF путевого листа и реестра рейсов через
   Android `PrintManager`, а не только `window.print()`.
7. **Синхронизация.** Опциональный self-hosted сервер или WebDAV,
   шифрование на устройстве, разрешение конфликтов.
8. **Виджеты.** Виджет «текущая смена» и быстрая кнопка «Заправка».
9. **Импорт из Excel/CSV с выбором колонок.** Сопоставление произвольных
   таблиц, предпросмотр и частичный импорт без замены всех данных.
10. **Архив справочников.** Скрывать устаревшие фирмы и места, не удаляя
    историю; отдельный экспорт только выбранных справочников.

## Качество и инфраструктура

- E2E-тесты в Playwright на реальном браузере (в CI).
- Скриншот-тесты мобильной и десктопной вёрстки.
- Локализация (ru/en) и формат валюты.
- Сборка release APK с собственным keystore и GitHub Releases.
- Автоматический деплой PWA на GitHub Pages.
- Миграционные тесты для старых версий localStorage.
- Телеметрия отсутствует; ошибки — только в локальный журнал.
