# АвтоПрофи

Офлайн-помощник для грузоперевозок: путевые листы, рейсы, заправки, финансы,
справочники и ИИ-агент по вашим данным. Работает как PWA в браузере и как
Android-приложение (WebView), без сервера, аккаунта и рекламы.

Проект вдохновлён интерфейсом приложения «АвтоПрофи 2.1» и повторяет его
рабочий сценарий: смена → путевой лист → рейсы → топливо → расчёт. Это
самостоятельная реализация, не связанная с оригиналом.

**Демо:** https://vladimirgorodok.github.io/autoprofi/
**Релизы и APK:** https://github.com/vladimirgorodok/autoprofi/releases

![Иконка АвтоПрофи](docs/icon-preview.png)

## Возможности

- **Главная** — текущая смена, прогресс маршрута, KPI за месяц, доход за
  7 дней, напоминания о ТО и ОСАГО, быстрые действия.
- **Путевые листы** — создание, выдача, закрытие смены с одометром и
  расходом топлива, печать листа, экспорт CSV.
- **Поездки** — планирование, статусы «планируется → в пути → завершён →
  оплачен», автоматический доход в финансах, карточка рейса.
- **Заправки** — журнал, расчёт расхода л/100 км, привязка к автомобилю и
  путевому листу. Цена топлива и денежный учёт не ведутся.
- **Финансы** — доходы и расходы, структура затрат, периоды, «Мой расчёт»,
  экспорт CSV.
- **Автомобили** — пробег, следующее ТО, ОСАГО, расход, VIN, тип ТС,
  примечание, выбор основного авто.
- **Справочники** — фирмы, места, грузы, АЗС и статьи расходов. Поиск,
  добавление, редактирование и удаление; подсказки в формах рейсов, листов,
  заправок и финансов.
- **ИИ-агент** — отвечает на вопросы по вашим данным локально (без сети).
  Опционально подключается любой OpenAI-совместимый API.
- **Архив данных** — экспорт ZIP с CSV-таблицами (как в файлах оригинала)
  и полной JSON-копией, импорт ZIP/JSON, замена или перенос данных.
- **PWA** — установка на домашний экран, офлайн-кеш, тёмная тема.

## Быстрый старт

Приложению не нужны сборка и зависимости — это статические ES-модули.

```bash
cd web
python3 -m http.server 8765
# откройте http://127.0.0.1:8765/
```

Подойдёт любой статический сервер (nginx, Caddy, GitHub Pages). Для PWA
нужен `http://localhost` или HTTPS — на нём регистрируется service worker.

Публикация на GitHub Pages (ветка `gh-pages`, без GitHub Actions):

```bash
scripts/deploy-pages.sh
```

Скрипт собирает `web/` и APK из `dist/` в отдельную ветку `gh-pages`.
В настройках репозитория источником Pages должна быть ветка `gh-pages`, папка `/`.

### Демо-данные

При первом запуске создаётся реалистичный набор: Volvo FH 460, активный
путевой лист, 11 рейсов, 6 заправок и финансы за месяц. Даты считаются
относительно текущего дня, поэтому демо всегда выглядит «живым».

Сбросить данные: **Настройки → Сбросить данные**. Ключ хранилища:
`autoprofi.state.v1`.

## Android APK

Скачать готовый APK: [последний релиз](https://github.com/vladimirgorodok/autoprofi/releases/latest)
или [зеркало на GitHub Pages](https://vladimirgorodok.github.io/autoprofi/download/autoprofi.apk)
(подписан debug-ключом, устанавливается на устройство/эмулятор).

**Что нового в 1.2.0:**

- Полноценный архив данных: **Настройки → Данные → Скачать архив**.
  Внутри ZIP — `01-vehicles.csv` … `11-finances.csv`, `manifest.json`,
  `README.txt` и полная копия `autoprofi.json`.
- Импорт архивов: ZIP или JSON. Понимает как архивы АвтоПрофи, так и
  CSV-архивы оригинала (включая `companies`, `cargos`, `places`, `periods`,
  `waybills`, `trips`, `stops`, `gas-stations`, `fuels`, `finances`).
  CSV имеют приоритет для таблиц, JSON — для настроек и истории чата.
- В карточки и формы добавлены поля из оригинальных данных: VIN и тип ТС,
  примечание автомобиля, вес груза и тип загрузки рейса, топливо на выезде
  и возврате, остановки маршрута.
- На Android экспорт открывает системный диалог «Создать документ», поэтому
  ZIP/CSV/JSON можно сохранить в Downloads или любое другое место.
- Данные версии 2 остаются совместимыми; миграция не требуется.

**Что нового в 1.1.0:**

- Справочники стали полноценными: фирмы, места, грузы, АЗС и статьи расходов
  можно добавлять, редактировать, искать и удалять. У мест есть фирма, адрес,
  контакт, координаты, тип загрузки и типовой груз.
- Справочники подставляются в формы: места и грузы — в рейсы и путевые листы,
  АЗС — в заправки, статьи — в финансы. При переименовании записи старые
  документы обновляются.
- Убраны цена топлива и денежный учёт заправок. Старые автоматические расходы
  на топливо удаляются при обновлении.
- Убран профиль водителя: водитель всегда один, поле в путевых листах не
  дублируется.
- Данные версии 1 автоматически переносятся в версию 2.

**Что было в 1.0.1:** исправлен показ HTML-кода вместо интерфейса в WebView
на Android 15/16 — MIME-тип в `WebResourceResponse` теперь передаётся без
параметра `charset` (он идёт отдельным аргументом). Также внешние ссылки
открываются в браузере, а при ошибке загрузки показывается экран с кнопкой
«Повторить».

Сборка:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"   # platforms;android-34, build-tools;34.0.0
export GRADLE_BIN="$(command -v gradle)"  # Gradle 8.x, либо Gradle wrapper

scripts/build-apk.sh debug                # Gradle
scripts/build-apk.sh --manual debug       # aapt/javac/d8/apksigner, без Gradle
```

Результат: `dist/autoprofi-v1.2.0.apk`. Иконки пересобираются из SVG:

```bash
scripts/make-icons.sh   # нужен rsvg-convert
```

APK — это WebView-обёртка без внешних зависимостей. Файлы сайта лежат в
`android/app/src/main/assets/www`, отдаются через
`https://appassets.androidplatform.net/` (`MainActivity.shouldInterceptRequest`).
Так работают localStorage и выбор файла для импорта. Кнопка «Назад» сначала
закрывает модалку, затем возвращает на главную, затем сворачивает приложение.

## Формат архива

Архив — обычный ZIP. Внутри:

| Файл | Содержимое |
| --- | --- |
| `manifest.json` | формат, версия, дата экспорта, количество записей |
| `README.txt` | краткая инструкция для человека |
| `autoprofi.json` | полная JSON-копия состояния |
| `01-vehicles.csv` | автомобили: VIN, тип, расход, пробег, ТО, ОСАГО |
| `02-companies.csv` | фирмы: реквизиты, контакты, типовой груз |
| `03-cargos.csv` | грузы |
| `04-places.csv` | места: фирма, адрес, координаты, тип загрузки |
| `05-periods.csv` | периоды путевых листов |
| `06-waybills.csv` | путевые листы, одометры, топливо |
| `07-trips.csv` | рейсы: вес, тип загрузки, начисление |
| `08-stops.csv` | остановки маршрута |
| `09-gas-stations.csv` | АЗС |
| `10-fuels.csv` | заправки без цены и стоимости |
| `11-finances.csv` | доходы и расходы |

CSV разделены `;`, кодировка UTF-8 с BOM. Импорт также понимает `,` и `\t`,
русские и английские заголовки, даты `ГГГГ-ММ-ДД` и `ДД.ММ.ГГГГ`.
При импорте ZIP с CSV и `autoprofi.json` таблицы берутся из CSV, а настройки
и чат — из JSON. Это позволяет править CSV в Excel и импортировать обратно.

```
  js/store.js        состояние, демо-данные, мутации, аналитика
  js/archive.js      ZIP/CSV-архив, импорт данных оригинала
  js/ui.js           иконки, модалки, тосты, графики, формы
  js/utils.js        даты, форматирование, CSV, download
  js/version.js      версия приложения и формата данных
  js/screens/        девять экранов

  manifest.webmanifest, sw.js

scripts/             сборка APK и иконок
docs/                изображения и дорожная карта
dist/                собранные APK
```

## ИИ-агент и приватность

По умолчанию агент работает **локально**: разбирает вопрос по ключевым
словам и считает ответ по данным из localStorage. Ничего не отправляется
в сеть.

В **Настройках → ИИ-агент** можно указать endpoint, модель и ключ любого
OpenAI-совместимого API. Тогда вопрос и обезличенная сводка (рейсы, листы,
топливо, финансы) уходят на выбранный сервер. Ключ хранится только на
устройстве. Для корпоративных данных используйте собственный шлюз.

## Технологии

- Vanilla JS + ES-модули, без фреймворков и сборщика.
- CSS custom properties, `color-mix`, safe-area, тёмная тема.
- localStorage, Blob/CSV, service worker, Web App Manifest.
- Android: Java, WebView, Gradle 8 / AGP 8.5, minSdk 24, targetSdk 34.

## Тесты

```bash
cd tests
npm install
npm test
```

Тесты поднимают приложение в jsdom, проходят по всем экранам, создают рейс,
заправку, лист, авто и операцию, проверяют печать, справочники, темы,
ИИ-агента, поиск, архив и «Ещё». Отдельные тесты проверяют миграцию данных
версии 1 → 2, удаление цены/водителя и переименование записей справочников
в старых документах. `tests/archive.mjs` проверяет CSV-парсер, ZIP-упаковку,
round-trip архива, импорт архива в стиле оригинала (включая deflate ZIP),
приоритет CSV над JSON и поля VIN/вес/загрузка/остановки.
