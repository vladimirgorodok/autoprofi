# АвтоПрофи

Офлайн-помощник водителя грузовика: путевые листы, рейсы, заправки, финансы,
справочники и ИИ-агент по вашим данным. Работает как PWA в браузере и как
Android-приложение (WebView), без сервера, аккаунта и рекламы.

Проект вдохновлён интерфейсом приложения «АвтоПрофи 2.1» и повторяет его
рабочий сценарий: смена → путевой лист → рейсы → топливо → расчёт. Это
самостоятельная реализация, не связанная с оригиналом.

**Демо:** https://vladimirgorodok.github.io/autoprofi/
**Релизы и APK:** https://github.com/vladimirgorodok/autoprofi/releases

![Иконка АвтоПрофи](docs/icon-preview.png)

## Возможности

- **Главная** — текущая смена, прогресс маршрута, KPI за месяц, доход за
  7 дней, напоминания о ТО и ОСАГО, быстрые действия.
- **Путевые листы** — создание, выдача, закрытие смены с одометром и
  расходом топлива, печать листа, экспорт CSV.
- **Поездки** — планирование, статусы «планируется → в пути → завершён →
  оплачен», автоматический доход в финансах, карточка рейса.
- **Заправки** — журнал, расчёт расхода л/100 км, средняя цена, привязка к
  автомобилю и путевому листу, автоматический расход в финансах.
- **Финансы** — доходы и расходы, структура затрат, периоды, «Мой расчёт»,
  экспорт CSV.
- **Автомобили** — пробег, следующее ТО, ОСАГО, расход, выбор основного авто.
- **Справочники** — контрагенты, грузы, адреса, статьи расходов.
- **ИИ-агент** — отвечает на вопросы по вашим данным локально (без сети).
  Опционально подключается любой OpenAI-совместимый API.
- **Данные** — localStorage, резервная копия JSON, импорт, сброс к демо.
- **PWA** — установка на домашний экран, офлайн-кеш, тёмная тема.

## Быстрый старт

Приложению не нужны сборка и зависимости — это статические ES-модули.

```bash
cd web
python3 -m http.server 8765
# откройте http://127.0.0.1:8765/
```

Подойдёт любой статический сервер (nginx, Caddy, GitHub Pages). Для PWA
нужен `http://localhost` или HTTPS — на нём регистрируется service worker.

Публикация на GitHub Pages (ветка `gh-pages`, без GitHub Actions):

```bash
scripts/deploy-pages.sh
```

Скрипт собирает `web/` и APK из `dist/` в отдельную ветку `gh-pages`.
В настройках репозитория источником Pages должна быть ветка `gh-pages`, папка `/`.

### Демо-данные

При первом запуске создаётся реалистичный набор: Volvo FH 460, активный
путевой лист, 11 рейсов, 6 заправок и финансы за месяц. Даты считаются
относительно текущего дня, поэтому демо всегда выглядит «живым».

Сбросить данные: **Настройки → Сбросить данные**. Ключ хранилища:
`autoprofi.state.v1`.

## Android APK

Скачать готовый APK: [последний релиз](https://github.com/vladimirgorodok/autoprofi/releases/latest)
или [зеркало на GitHub Pages](https://vladimirgorodok.github.io/autoprofi/download/autoprofi.apk)
(подписан debug-ключом, устанавливается на устройство/эмулятор).

**Что нового в 1.0.1:** исправлен показ HTML-кода вместо интерфейса в WebView
на Android 15/16 — MIME-тип в `WebResourceResponse` теперь передаётся без
параметра `charset` (он идёт отдельным аргументом). Также внешние ссылки
открываются в браузере, а при ошибке загрузки показывается экран с кнопкой
«Повторить».

Сборка:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"   # platforms;android-34, build-tools;34.0.0
export GRADLE_BIN="$(command -v gradle)"  # Gradle 8.x, либо Gradle wrapper

scripts/build-apk.sh debug                # Gradle
scripts/build-apk.sh --manual debug       # aapt/javac/d8/apksigner, без Gradle
```

Результат: `dist/autoprofi-v1.0.1.apk`. Иконки пересобираются из SVG:

```bash
scripts/make-icons.sh   # нужен rsvg-convert
```

APK — это WebView-обёртка без внешних зависимостей. Файлы сайта лежат в
`android/app/src/main/assets/www`, отдаются через
`https://appassets.androidplatform.net/` (`MainActivity.shouldInterceptRequest`).
Так работают localStorage и выбор файла для импорта. Кнопка «Назад» сначала
закрывает модалку, затем возвращает на главную, затем сворачивает приложение.

## Структура

```
web/                 статическое приложение
  index.html         каркас и подключение модулей
  styles.css         дизайн-система, адаптив, тёмная тема, печать
  js/app.js          роутер, каркас, глобальные действия
  js/store.js        состояние, демо-данные, мутации, аналитика
  js/ui.js           иконки, модалки, тосты, графики, формы
  js/utils.js        даты, форматирование, CSV, download
  js/screens/        девять экранов
  icons/             SVG + PNG-иконки
  manifest.webmanifest, sw.js
android/             WebView-проект (Gradle)
scripts/             сборка APK и иконок
docs/                изображения и дорожная карта
dist/                собранные APK
```

## ИИ-агент и приватность

По умолчанию агент работает **локально**: разбирает вопрос по ключевым
словам и считает ответ по данным из localStorage. Ничего не отправляется
в сеть.

В **Настройках → ИИ-агент** можно указать endpoint, модель и ключ любого
OpenAI-совместимого API. Тогда вопрос и обезличенная сводка (рейсы, листы,
топливо, финансы) уходят на выбранный сервер. Ключ хранится только на
устройстве. Для корпоративных данных используйте собственный шлюз.

## Технологии

- Vanilla JS + ES-модули, без фреймворков и сборщика.
- CSS custom properties, `color-mix`, safe-area, тёмная тема.
- localStorage, Blob/CSV, service worker, Web App Manifest.
- Android: Java, WebView, Gradle 8 / AGP 8.5, minSdk 24, targetSdk 34.

## Тесты

```bash
cd tests
npm install
npm test
```

Тест поднимает приложение в jsdom, проходит по всем экранам, создаёт рейс,
заправку, лист, авто и операцию, проверяет печать, справочники, темы,
ИИ-агента, поиск, архив и «Ещё».
